# Política de Privacidade - Hermes Big Z Casa

Última atualização: 18 de novembro de 2026.

O Hermes Big Z Casa é um assistente pessoal usado somente pelo próprio dono, no computador dele. Não há outros usuários.

Dados acessados: com a autorização do dono, o app lê e-mails do Gmail, arquivos do Google Drive, compromissos do Google Agenda e contatos, e pode criar arquivos e compromissos quando o dono pede.

Como os dados são usados: apenas para responder aos pedidos do próprio dono. Os dados não são vendidos, não são usados para publicidade e não são compartilhados com terceiros, exceto o serviço de inteligência artificial que gera as respostas pedidas pelo dono.

Armazenamento: a chave de acesso fica guardada apenas no computador do dono. O app não mantém cópias dos e-mails ou arquivos em servidores próprios.

Como cancelar: o dono pode retirar o acesso a qualquer momento em https://myaccount.google.com/permissions

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
